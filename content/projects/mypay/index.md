At MyPay, I own end-to-end backend and frontend work on a visual website editor and employee management system. I am also helping rewrite a roughly 200,000-line legacy frontend, primarily on the frontend with some backend contributions.

The modern merchant-portal stack includes React, TypeScript, Vite, TanStack Query and Router, Tailwind CSS, React Hook Form, and Zod. The tooling includes Biome, Vitest, Testing Library, MSW, and Playwright.

The rewrite is ongoing and uses AI-assisted development.
