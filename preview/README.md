# Portfolio preview

Download `portfolio-preview.zip`, extract it, and open `index.html` in your browser.

The package contains the redesigned portfolio, project case studies, writing, self-hosted fonts, search, and demo videos. It does not need Hugo or Node to view.

If your browser restricts local file access, run `python3 -m http.server 8000` from the extracted folder and open the local server in your browser.

This is a review artifact on a separate preview branch. It does not replace the production site.
